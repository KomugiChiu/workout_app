# 飛鳥完整拆解（全分支）

> **收錄日期**：2026-11-02
> **定位**：手肘角度鎖死的「肩水平內收」孤立動作——胸肌拉長＋頂端擠壓，臥推的最佳輔助。
> **一句話**：手肘凍結、胸帶手抱、頂端夾扁。

---

## 🔀 飛鳥 vs 臥推

| | 臥推 | 飛鳥 |
|---|---|---|
| 手肘 | 不斷屈伸 | **角度鎖死（15–30°）** |
| 主動關節 | 肘 | **肩水平內收** |
| 重量 | 較重 | 約臥推 50–60% |
| 強項 | 力量、三頭 | 胸肌孤立、拉伸＋擠壓 |

---

## 📋 分支總覽

### 按角度

| 版本 | 角度 | 主吃 | 備註 |
|------|------|------|------|
| 地板飛鳥 | 0°（地板限制） | 胸中下部 | 最肩友善 |
| 平板飛鳥 | 0°（椅） | 胸整體 | 拉伸比地板大 |
| 上斜飛鳥 | 15–45° | **上胸** | 30° 甜蜜點 |
| 下斜飛鳥 | -15–30° | 下胸 | 居家可跳過 |

### 按器材

| 器材 | 版本 | 特性 |
|------|------|------|
| 啞鈴 | 地板／上斜／單手飛鳥 | 最經典、重量好調 |
| 壺鈴 | 單手或雙壺鈴地板飛鳥 | 8kg 偏重 → 半行程慢速 |
| 彈力帶 | 站姿繞背／固定點飛鳥 | **頂端最重**、擠壓感強 |
| TRX | 站姿前傾飛鳥 | 懸吊不穩定、核心一起練 |
| 機械／纜繩 | 飛鳥機、Cable Crossover | 器材需求較高 |

### 按執行方式

| 版本 | 說明 |
|------|------|
| 雙手飛鳥 | 標準主力 |
| 單手飛鳥 | 矯正左右差、抗旋 |
| 等長飛鳥 | 胸前夾住停 20–30 秒，收尾泵感 |
| 反向飛鳥 | 後三角（拮抗親戚，不是胸） |

## 🎬 各版本詳解

### ① 地板啞鈴飛鳥（最推薦起點）

**影片**：
- [How To Do A Dumbbell Floor Fly](https://www.youtube.com/watch?v=bgC53-J-6gA)
- [How To Perform The 2 Dumbbell Floor Flies](https://www.youtube.com/watch?v=II2kKKstoRg)

- 躺地、膝彎腳踩地，雙鈴在胸口正上方（可用中性握）
- 手肘微彎鎖住 → 往兩側畫弧到上臂輕觸地面
- 吐氣抱回，頂端想像「夾扁一顆球」，輕碰不互撞
- 🔴 手肘角度漂移（變半臥推）／下降太快／重量太重
- 節奏：3 秒下 → 頂端 1 秒 → 1 秒回

### ② 上斜啞鈴飛鳥（補上胸）

**影片**：
- [How To: Incline Dumbbell Fly](https://www.youtube.com/watch?v=bDaIL_zKbGs)
- [How to Do an Incline Dumbbell Fly](https://www.youtube.com/watch?v=vE9KK77nddw)

- 椅背 **30°**（超過 45° 變肩推）；重量比平板再輕一級
- 肩胛先後收下壓，胸口微挺再開始
- 下降至手臂與地面平行附近即可，不必硬拉到底
- 🔴 肩膀前傾、聳肩、用甩的

### ③ 單手啞鈴飛鳥

**影片**：
- [How to Do a One-Arm Dumbbell Bench Fly](https://www.youtube.com/watch?v=7LnGW4ik3hU)
- [How To Do A Single Arm Dumbbell Fly](https://www.youtube.com/watch?v=07K2vAqFMfE)

- 躺地或躺椅，單手做；另一手可放胸口感受張力或扶地
- 身體會想旋轉 → 核心抗旋，骨盆釘住
- 🔴 軀幹跟著轉、另一側肩膀離地

### ④ 壺鈴地板飛鳥

**影片**：
- [Kettlebell Chest Fly](https://www.youtube.com/watch?v=KMTdgImBA3o)
- [Chest Kettlebell Fly](https://www.youtube.com/watch?v=2Xn01bRRVzA)

- 單顆 8kg 就做**單手版**（另一手扶地／放胸）；雙顆才做雙手版
- 8kg 對飛鳥偏重 → **只做 60–70% 行程、3 秒慢放**
- 壺鈴重心在把手下方，手腕保持中立不後折
- 🔴 用壺鈴硬拉到底、手腕折、行程失控

### ⑤ 彈力帶站姿飛鳥

**影片**：
- [Standing Chest Fly Using Resistance Bands](https://www.youtube.com/watch?v=UpyX0O740Gg)
- [How to perform a Standing Chest Fly with Resistance Bands](https://www.youtube.com/watch?v=fuRVxOPDPcE)

- 帶子繞過上背（肩胛下方）、雙手抓兩端，站弓步
- 往前抱合到胸前，頂端停 1 秒（張力最大在末端）
- **固定點版**：錨點在身後胸高，站弓步往前推合
- 🔴 帶子滑到脖子、起始沒張力（前半等於沒練）

### ⑥ TRX 飛鳥

**影片**：
- [Exercise Tutorial: TRX Chest Fly](https://www.youtube.com/watch?v=ppwfrwUoDls)
- [TRX Chest Fly — Fit Father](https://www.youtube.com/watch?v=VeiB4nfSpeQ)

- **背對錨點**、雙手握把、手臂張開如 T、身體前傾
- 把手往胸前靠攏 → 慢回；腳越往前越難
- 8–12 下即可，穩定優先
- 🔴 手肘彎掉、身體上下晃、肩聳起

### ⑦ 反向飛鳥（啞鈴／彈力帶）— 後三角親戚

**影片**：
- [How To Dumbbell Reverse Fly PROPERLY](https://www.youtube.com/watch?v=d1QEddtoOq0)
- [Reverse Fly Tutorial — Proper Form](https://www.youtube.com/watch?v=3MKmYlhxgOo)
- [Resistance Band Reverse Fly](https://www.youtube.com/watch?v=cyihFNmsq-A)
- [Band Reverse Fly](https://www.youtube.com/watch?v=38leTE2yI1)

- 俯身（髖鉸鏈、背平）雙手持鈴往兩側打開，肘微彎
- 彈力帶版：錨點在身前胸高、雙手拉開
- 重量要**輕**（後三角小），12–15 下
- 🔴 用斜方拉、耸肩、甩甩

## 🏋️ 你的器材可以做哪些？

| 器材 | 可做的飛鳥 |
|------|-----------|
| **1–10kg 啞鈴成對** ⭐ | 地板飛鳥、上斜飛鳥、單手飛鳥、反向飛鳥、等長夾胸 |
| **8kg 壺鈴 ×1** | 單手地板飛鳥（半行程）、等長夾胸負重 |
| **30kg 彈力帶** | 站姿繞背飛鳥、固定點飛鳥、**反向飛鳥**（最適合） |
| **TRX** | 站姿飛鳥、上斜飛鳥（腳前移降難度）、TRX 反向飛鳥 |
| **重訓椅** | 上斜飛鳥、平躺飛鳥（比地板行程大） |
| **1kg 啞鈴** | 熱身組、技術練習、20–25 下收尾 |

## 📈 課表安排

- **頻率**：每週 1–2 次，放在推日（臥推後）當輔助
- **組次**：3 組 × 10–15 下，RPE 7–8；上斜與 TRX 取 8–12
- **節奏**：3 秒下 → 頂端夾 1 秒 → 1 秒回
- 想加強上胸：上斜飛鳥優先
- 想省器材：地板飛鳥＋彈力帶站姿飛鳥就夠

## ⚠️ 安全提醒

- 肩膀前側刺痛、夾擠感 → 停：降重、縮行程、改地板版
- 手肘鎖死是大忌（關節壓力全集中在肘）
- 重量過重會自動變成「半臥推」——寧輕勿重
- 飛鳥是**孤立動作**，放在大動作之後，不要當第一個
