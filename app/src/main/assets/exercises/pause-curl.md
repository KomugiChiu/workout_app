# 三停彎舉完整拆解（3-Stop Pause Curl）

> **收錄日期**：2026-11-02
> **定位**：在彎舉的三個角度各停 2–3 秒——拉長張力時間（TUT）、強化「卡住的角度」，完全無法用甩的。
> **一句話**：慢到不行，但二頭會記住。

## 🔀 與「21 響禮炮」的差別

| | 三停彎舉（本篇） | 21s |
|---|---|---|
| 做法 | 同一趟在**三個角度各停 2–3 秒** | 下半程 7 下＋上半程 7 下＋全程 7 下 |
| 重點 | **等長停頓**、弱點角度 | 分段次數、泵感 |
| 重量 | 正常彎舉 **60–70%** | 正常彎舉的 50% 左右 |

## 📐 三個停點

```
頂端（完全收縮）      ● 停 2–3 秒
90°（最費力角度）     ● 停 2–3 秒
起始 45°             ● 停 2–3 秒
```

一下約 8–10 秒；**全程 3 秒慢放**。

## 🏃 流程（5 步）

1. 站姿或坐姿，雙手持鈴垂身側（掌心朝前或錘式握）
2. 手肘**固定在身側**（想像夾住一張紙）
3. 彎到 45° 停 2 秒 → 90° 停 2 秒 → 頂端停 2 秒
4. 3 秒慢放回起始 45°，停 2 秒＝一下完成
5. 全程吐氣上、吸氣下，**肩膀放鬆不聳**

## ✅ 檢查點

- 手肘位置整組不變（不往前跑）
- 身體不後仰借力
- 手腕中立、不往手背折
- 頂端二頭「硬」而不是前臂痠

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 重量太重 | 停不住、變甩鈴 | 降到正常彎舉 60%，寧輕勿重 |
| 手肘往前跑 | 前三角代償 | 手肘釘在身側 |
| 身體後仰 | 下背出力 | 靠牆做或坐姿 |
| 停頓用「撐」的 | 抖動、代償 | 降重，停的 2 秒要穩 |
| 手腕後折 | 腕關節壓力 | 手腕中立、指節朝前 |

## 🔀 變化

| 版本 | 做法 | 重點 |
|------|------|------|
| 錘式三停 | 掌心相對 | 多練**肱橈肌**（前臂外側） |
| 彈力帶三停 | 踩帶、雙手抓兩端 | 頂端阻力最大 |
| 單手靠椅 | 手肘頂在椅上 | 最穩定、最孤立 |
| 離心三停 | 只在下放時停三個點 | 離心刺激更強 |

## 📈 訓練量

- **2–3 組 × 6–10 下**（因一下很慢，次數少），組間 60 秒
- RPE 8：最後 2 下停頓開始抖但位置不跑
- 進步：先加「停的秒數」（2→3 秒）→ 再加次數 → 最後加重

## 🏋️ 你的器材

- 啞鈴 2–4kg 起（1kg 熱身組）
- 8kg 壺鈴偏重 → 建議不用，或改「等長夾住」版本
- 30kg 彈力帶：踩帶版可行，但注意起始張力

## ⚠️ 前臂提醒

三停彎舉會大量使用**肱橈肌（前臂外側）**——之前 TRX 後外側痠過的部位。若當天還有感，重量砍半或改錘式以外版本；正常恢復後再做沒問題。

## ⚠️ 安全

- 手肘當下刺痛（非肌肉痠）→ 停，檢查是否重量過重或肘位置跑掉
- 彎舉是**輔助動作**，放在大動作之後，不要當第一個
