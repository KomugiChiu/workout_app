# 錘式彎舉完整拆解（Hammer Curl）

> **收錄日期**：2026-11-02
> **定位**：掌心相對的彎舉——比一般彎舉多練**肱肌＋肱橈肌**，讓手臂看起來更厚。
> **一句話**：像握著錘子往上敲，全程掌心相對。

## 💪 主練肌群

| 肌肉 | 角色 |
|------|------|
| 肱肌（Brachialis） | 主力，位於二頭下方，增加手臂**厚度** |
| 肱橈肌（Brachioradialis） | 前臂外側，讓前臂更飽滿 |
| 肱二頭肌 | 輔助（比旋轉手腕的彎舉少一點） |

## 🔀 與一般彎舉的差別

| | 一般彎舉 | 錘式彎舉 |
|---|---|---|
| 握法 | 掌心朝上（旋後） | **掌心相對（中立）** |
| 主力 | 肱二頭 | **肱肌＋肱橈肌** |
| 視覺效果 | 二頭峰 | **手臂整體厚度** |
| 手腕壓力 | 較大 | **較小（中立位）** |

---

## 🏃 做法（5 步）

1. 站姿，雙手持啞鈴垂身側，**掌心相對**（像握錘子）
2. 手肘固定在身側，肩膀下沉
3. 前臂往上彎，**全程保持掌心相對**（不要轉成掌心朝上）
4. 頂端停 1 秒，感受前臂外側＋二頭下段
5. 3 秒慢放回起始

## ✅ 檢查點

- 手肘不前後跑、不夾緊身體
- 身體不後仰借力
- 手腕中立、不往手背折（對前臂外側友善）
- 重量：4–6kg 做 10–12 下，最後 2 下有餘力

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 甩上去 | 二頭沒吃到 | 降重、慢放 3 秒 |
| 手肘往前跑 | 前三角代償 | 手肘釘在身側 |
| 手腕轉成旋後 | 變成一般彎舉 | 全程掌心相對 |
| 聳肩 | 斜方代償 | 肩離耳 |
| 重量太重 | 前臂先爆 | 寧輕勿重 |

## 🔀 變化

| 版本 | 做法 | 重點 |
|------|------|------|
| 交叉錘式 | 往對側肩膀方向彎 | 肱肌刺激更多 |
| 交替錘式 | 左右輪流 | 專注單邊 |
| 單手壺鈴 | 8kg 壺鈴角握 | 單邊＋握力 |
| 彈力帶 | 踩帶、掌心相對 | 頂端阻力最大 |

## 📈 訓練量

- **2–3 組 × 10–12 下**，組間 45–60 秒
- RPE 7–8：最後 2 下有餘力
- 放在手臂日或拉日最後；與三頭下壓／伸展可做**拮抗超級組**

## 🏋️ 你的器材

- 啞鈴 4–6kg ×2（主力）
- 8kg 壺鈴：單手角握版
- 30kg 彈力帶：踩帶版（注意起始張力）

## ⚠️ 安全提醒

- 手肘當下刺痛（非肌肉痠）→ 停，檢查重量與肘位置
- 前臂外側曾痠痛者：錘式比旋後彎舉友善，但仍從輕重量開始
- 彎舉是輔助動作，放在大動作之後
