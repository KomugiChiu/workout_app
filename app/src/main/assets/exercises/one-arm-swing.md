# 單手壺鈴擺盪完整拆解（One-Arm Kettlebell Swing）

> **收錄日期**：2026-11-02
> **定位**：雙手擺盪的進階版——同一個髖爆發，加上**抗旋核心**與單邊握力。
> **一句話**：髖鉸鏈的彈，手臂是繩子，身體不轉。

## 🔀 單手 vs 雙手

| | 雙手擺盪 | 單手擺盪（本篇） |
|---|---|---|
| 負荷 | 較重 | 同重量下更吃力 |
| 核心 | 抗伸展 | **抗旋轉＋抗側屈** |
| 握力 | 雙手分擔 | 單手極限 |
| 節奏 | 連續 | 換手需練習 |

> 單手是同重量「變難」的免費升級——8kg 可以玩很久。

## 🧘 準備

1. 腳比肩寬、腳尖微外；壺鈴放身前約一腳距離
2. 單手抓握（手指扣好、手腕中立），另一手自然張開平衡
3. 髖往後推、背平，把鈴**往胯下 hiking 拉回**（第一下）
4. 肩膀下沉，手臂放鬆——從第一下起手臂就不出力

## 🏃 流程（4 拍）

1. **後擺**：鈴往胯下走，吸氣、腿後繃緊
2. **爆發**：臀＋腿後收，髖往前「撞」——鈴被甩到胸口高度
3. **頂端**：身體站直成平板（臀夾、肋骨下收），短促吐氣
4. **回擺**：等鈴掉回來再屈髖接住，**不要追鈴**

**換手時機**：在頂端「失重瞬間」換手（進階）；或一組做完再換邊（安全版）。

## ✅ 檢查點

- 軀幹**不旋轉**：肩膀始終面向前方（抗旋是重點）
- 鈴的路徑是前後直線，不左右飄
- 頂端身體站直、不後仰
- 腳掌全程黏地、無聲

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 蹲著做（膝大彎） | 變深蹲甩鈴 | 膝凍結、屁股找牆 |
| 用肩舉鈴 | 肩夾擠 | 想「髖撞鈴飛」 |
| 身體跟著轉 | 失去抗旋訓練 | 空手先練「站直+髖」 |
| 換手太早／太晚 | 節奏亂、打到手 | 先在頂端停一拍再換 |
| 握太緊 | 前臂先爆 | 手指輕扣、鈴掛虎口 |
| 頂端後仰 | 腰椎壓力 | 站直＋臀夾即停 |

## 📈 進階路線

```
雙手擺盪 → 單手擺盪 → 單手 High Pull → 單手抓舉 Snatch
```

- **Snatch（抓舉）**：鈴從胯下直接甩到頭頂鎖定，技術門檻高；先確認單手擺盪完全穩定再練
- 8kg 練 Snatch 可以，但次數少、品質優先

## 📊 訓練量

- **3 組 × 10 下／邊**（一組一邊做完再換），組間 60–90 秒
- 或 EMOM：每分鐘 8–10 下／邊，共 8–10 分鐘
- RPE 7–8：最後幾下髖速掉但背不圓

## 🏋️ 你的器材

- 8kg 壺鈴 ×1：本動作主場
- 想更難：加**停頓**（頂端停 1 秒）或改**換手版**
- 30kg 彈力帶：不適合（擺盪需要離心自由重量）

## ⚠️ 安全提醒

- 下背當下刺痛 → 停：九成是蹲著做或圓背
- 握力先爆（鈴要飛出去）→ 放下休息，不要硬勾
- 場地前後淨空（鈴飛出去不會砸到人或鏡子）
- 有肩夾擠病史：只做低擺盪（到肚臍高度）
