# 阿諾德推舉完整拆解（Arnold Press）

> **收錄日期**：2026-11-17
> **定位**：前束＋中束的綜合肩推——旋轉只是手段，**時機**才是重點。
> **一句話**：啞鈴先往前、手腕疊在肘上，推到**額頭高度**才開始轉腕。

## 🧠 先搞懂：它到底練什麼

阿諾德·史瓦辛格設計這個動作，是想一次練到整個三角肌（前、中、後）。但實際上：

- **後束對整個推舉只有約 11% 的貢獻**——想靠阿諾德推舉練後束，效率很低
- 真正的目標是 **前束＋中束**
- 想專練後束，要選「肘部能往身體後方伸」的動作：坐姿纜繩划船、反向飛鳥、W Raise

> 這也是為什麼阿諾德推舉常被排在推日，而不是拿來補後三角。

**設計本意**：讓訓練重心在推舉過程中，從前束**平穩過渡**到中束——旋轉只是手段，不是目的。

## 🧘 起始姿勢（第一個最常錯的點）

| 做法 | 結果 |
|------|------|
| 啞鈴直接擱在前三角上 | 前臂向後斜、關節沒疊好；手腕／肘壓力大，前束底部沒張力 |
| 啞鈴稍微往前舉、手腕疊在肘上 | 支撐更好、關節壓力小，前束一開始就有張力 |

**正確**：

1. 坐姿或站姿，雙手中性握（掌心朝向自己）持鈴在肩前
2. 啞鈴**稍微往前舉**，離開前三角
3. 側面看，**手腕正好疊在肘部正上方**
4. 手肘在身體前方，不是完全外展開 90°

這樣做可以減少手腕與肘的壓力，也讓前束在一開始就有張力。

## 🔄 旋轉時機（動作的核心）

| 轉的時機 | 結果 |
|------|------|
| **太早轉** | 手肘提早外開 → 負荷跑到中束、肩胛節律被打亂、增加肩部不適風險 |
| **太晚轉** | 手肘全程留在身前 → 幾乎全部給前束 |
| **原地旋轉（只轉不推）** | 一轉就變成中束推舉，前束幾乎沒吃到 |
| **正確：推到額頭高度才轉** | 前束與中束平均分攤，這才是阿諾德推舉的本意 |

- 全程在**肩胛骨平面**推：手肘略微向前，不要完全外展成「頸後推舉」
- 肩胛平面大約是身體**往前 30°** 的平面；手肘上限是「身體正側面的前方一點點」，不要整個跑到側面
- 轉腕要順，不要突然甩；到頂點掌心朝前（或斜前）
- 頂點手肘保持微屈，不鎖死

## 🏃 做法（7 步）

1. 坐姿或站姿，雙手中性握持鈴在肩前
2. 啞鈴稍微前移，手腕疊在肘上、核心繃緊
3. 吸氣，往上推，手肘保持略前（肩胛平面）
4. 推到**額頭高度**，開始把掌心往外轉
5. 繼續推到頂點，吐氣，手肘不鎖死
6. 吸氣，控制下放；過額頭高度後再慢慢轉回掌心朝自己
7. 回到起始位置，重新確認手腕疊在肘上再下一手

## ✅ 檢查點

- 側面看：手腕一直疊在肘上（不要讓啞鈴掉到前三角）
- 手肘略往前，最多到「正側面的前方一點點」，不往外飛、不往身後
- **額頭高度**才開始轉腕
- 肩膀不聳、肋骨不翻、腰不拱
- 頂點手肘微彎，重量由肌肉控制，不是關節撐住
- 下放 2–3 秒，不要讓啞鈴直接掉回肩上

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 啞鈴擱在前三角上 | 手腕／肘壓力、前束沒張力 | 稍微前舉，手腕疊肘 |
| 太早外轉 | 手肘外開、變中束推舉、肩胛節律亂 | 到額頭高度再轉 |
| 太晚外轉 | 幾乎全給前束 | 額頭高度就開始轉 |
| 原地旋轉後才推 | 全程變中束推舉 | 先垂直推到額頭，再邊推邊轉 |
| 手肘完全外展 90° | 接近頸後推舉、肩夾擠風險 | 肘略前，走肩胛平面 |
| 手肘滑到身體後方 | 變成頸後推舉、肩袖壓力 | 手肘留在正側面前方一點點 |
| 頂點鎖死手肘 | 關節壓力 | 保持微屈 |
| 坐姿蹬地、背頂死椅背 | 肩胛節律被打亂 | 背輕貼、核心穩、降重量 |
| 重量太重、腰拱借力 | 下背代償 | 降重、收肋骨、改站姿輕重量 |
| 甩動手臂／甩腕 | 軌跡不穩、手腕與肩壓力 | 降重、放慢，讓肌肉控制 |

## 🔀 坐姿 vs 站姿

| | 站姿 | 坐姿 |
|---|---|---|
| 重量 | 較輕（核心需求高） | 較重 |
| 優點 | 運動員姿態、核心一起練、可輕微腿驅動 | 穩定、專注肩部 |
| 注意 | 不要用腰甩 | **不要蹬地把背頂死椅背** |

> 原教學（ATHLEAN-X）偏好站姿；坐姿不是錯，但別為了舉更重而讓背緊貼椅背、腳死命蹬地。

**為什麼不能壓椅背**：手臂舉過頭時，肩胛骨必須跟著上旋，肩關節與肩胛大約是 **2：1** 的節律（手臂外展 2°，肩胛轉 1°）。把身體壓死椅背會打亂這個節律，推舉軌跡與肩關節力學都會變差。坐姿時身體稍微坐前面一點、背輕貼即可。

## 🔀 變化

| 版本 | 做法 | 重點 |
|------|------|------|
| 標準版（站姿） | 站姿、核心繃緊 | 原教學最推薦 |
| 坐姿靠背 | 椅背 80–90°，背輕貼 | 穩定、適合新手 |
| 單手版 | 一手持鈴、一手扶腰／腿 | 矯正左右差、可看鏡子 |
| 壺鈴版 | 8kg 壺鈴單手 | 重量偏重 → 次數降低、行程縮小 |
| 彈力帶版 | 踩帶、雙手持帶 | 頂端張力最大、居家替代 |
| 中立握肩推 | 不轉腕，掌心相對 | 旋轉時機抓不到時先做這個 |

## 📈 訓練量

- **3 組 × 8–12 下**，RPE 7–8
- 每週 1–2 次，放在推日**第一個或第二個**動作
- 站姿先用 2–6kg 抓時機；坐姿可到 8–10kg
- 與側平舉搭配：阿諾德推舉吃前＋中，側平舉補中束
- **後束另外排**（反向飛鳥／W Raise），不要期待這個動作練到後束

## 🏋️ 你的器材

- **啞鈴 2–10kg ×2** ⭐（站姿 2–6kg、坐姿 5–10kg 起）
- **8kg 壺鈴 ×1**：單手版，重量偏重 → 慢速、少次數
- **30kg 彈力帶**：踩帶站姿版
- **重訓椅**：坐姿靠背版（背輕貼，不頂死）
- **TRX**：不適合（推舉軌跡無法對應）

## ⚠️ 安全提醒

- 肩膀前側夾擠、刺痛 → 停：縮小行程、改中立握、降重量
- 手腕痛 → 檢查是否啞鈴擱在前三角、手腕有沒有折
- 下背拱、肋骨翻 → 降重或改坐姿靠背
- 旋轉過程不順、有卡頓 → 先不轉腕，做中立握肩推
- 曾經肩夾擠、肩袖受傷 → 先諮詢醫師／物理治療師
