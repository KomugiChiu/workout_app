## 🧠 為什麼要練 W Raise

後三角（三角肌後束）有三個主要動作，W Raise 是少數能一次全包的動作：

| 功能 | 動作方向 | 反向飛鳥 | W Raise |
|------|----------|:---:|:---:|
| 肩水平外展 | 手臂往兩側打開 | ✅ | ✅ |
| 肩伸 | 上臂往身體後方伸 | 少量（器械版較多） | ✅ |
| 肩外轉 | 上臂向外旋轉 | ❌ | ✅ |

> larry_physio：「三角後束的主要動作是肩後伸、肩外展、肩外轉。反向飛鳥器械不是不能做，但因為器材限制，用到最多的是肩伸，外轉跟外展的比例會被犧牲。」

- 反向飛鳥主練「水平外展」；器械／纜繩版因固定軌跡，肩伸比例變高、外展與外轉被犧牲
- W Raise 的肘彎 90° 讓「肩伸」與「外轉」可以疊在同一個行程裡

### ⚖️ 手肘開一點，後三角吃更多

- 手肘越**貼身**、外轉越多 → 小圓肌／棘下肌接手，後三角參與下降
- 手肘**略外開（約 45–60°）**、外展變多 → 後三角張力更集中

> 原貼文作者對影片的建議就是「手肘再開多一點」，用更多外展避免其他外轉肌搶走刺激。

## 💪 主練肌群

| 肌肉 | 角色 |
|------|------|
| 三角肌後束 | **主力**（肩伸＋水平外展＋外轉） |
| 小圓肌、棘下肌 | 外轉輔助（肘越貼身、外轉越多，參與越高） |
| 中下斜方、菱形肌 | 肩胛穩定與回縮 |
| 核心 | 俯身姿勢維持、抗旋 |

## 🧘 準備

1. **坐姿俯身**：坐在平凳前緣，髖往前折，背部打直、胸口朝下（角度約 45°）
2. 雙手中性握（掌心相對）持啞鈴，手臂自然垂在肩膀正下方
3. 手肘彎約 **90°** 並固定，前臂朝下
4. 重量 **1–4kg** 起——後三角很小，寧輕勿重

## 🏃 做法（6 步）

1. 吸氣，肩胛微收下壓、核心繃緊，頸部放鬆
2. 吐氣，用**手肘**帶動，把上臂往身體後方伸（肩伸）
3. 伸到底不停，繼續把**手往上抬**（水平外展）
4. 同時讓前臂往上、往外翻，做出**外轉**（手背朝上／外）
5. 頂點停 1 秒，感覺後三角收緊
6. 吸氣，3 秒慢回起始位置，重新設定再下一手

## ✅ 檢查點

- 全程用**肘**帶，不是用手腕把重量勾起來
- 手肘角度固定，不要變成彎舉或划船
- 肩膀不聳起、脖子不緊
- 手肘略外開（45–60°），不要死死夾在身側
- 頂點是「後三角收縮」，不是「斜方夾背」
- 下放要慢，張力不能掉

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 甩動借力 | 後三角沒吃到，全給 momentum | 降重量、3 秒慢放 |
| 聳肩 | 斜方接手、脖子緊 | 肩胛先下壓，想著肘帶頭 |
| 手肘角度一直變 | 變成划船／彎舉 | 固定 90°，只想肘的軌跡 |
| 手肘太貼身 | 小圓肌／棘下肌搶戲 | 手肘外開一點，多做外展 |
| 重量太重 | 行程變短、外轉消失 | 1–4kg，品質優先 |
| 站姿腰代償 | 下背壓力 | 改坐姿或上斜椅胸靠 |
| 手抬過高變成耸肩 | 肩夾擠風險 | 抬到接近肩高即可 |

## 🔀 變化

| 版本 | 設定 | 特性 |
|------|------|------|
| 坐姿俯身（影片版） | 坐平凳前緣、髖鉸鏈 | 最好抓角度，居家首選 |
| 站姿髖鉸鏈 | 站姿、背平、膝微彎 | 核心參與多，也容易借力 |
| 上斜椅胸靠 | 椅背 30–45°，胸貼椅 | 最孤立、下背最輕鬆 |
| 俯臥地板／瑞士球 | 趴地或趴球，徒手或極輕啞鈴 | 行程短、新手友善 |
| 彈力帶 | 踩帶或固定點，手肘固定 90° | 頂端張力最大 |
| 單手 | 一手扶凳、一手做 | 矯正左右差、可看鏡子 |

## 🔁 超級組：反向飛鳥 ＋ W Raise

影片最後提到的「deadly combo」：

- **A1** 反向飛鳥（器械／啞鈴／彈力帶）12–15 下
- **A2** W Raise 12–15 下
- 兩個動作之間不休息，做完休息 **60–75 秒**，共 2–3 輪
- 反向飛鳥先練水平外展，W Raise 補肩伸＋外轉，三個功能一次收齊
- 前提是兩個動作都已經做對；疲勞時先降重量，不要用甩的

## 📈 訓練量

- **3 組 × 12–15 下**，RPE 7–8
- 每週 1–2 次，放在推日最後或拉日
- 節奏：2 秒上 → 頂點 1 秒 → 3 秒下
- 與反向飛鳥同天時，W Raise 可減為 2 組

## 🏋️ 你的器材

- **啞鈴 1–4kg ×2** ⭐（5kg 以上通常只能半行程）
- **8kg 壺鈴 ×1**：單手版，重量偏重 → 慢速、縮小行程
- **30kg 彈力帶**：固定點或踩帶版
- **重訓椅**：坐姿俯身或上斜胸靠
- **TRX**：不適合（張力方向不對）

## ⚠️ 安全提醒

- 肩膀前側夾擠、刺痛 → 停：降重量、縮小外轉幅度
- 頸部緊、頭暈 → 檢查是否聳肩或憋氣
- 下背不適 → 改上斜椅胸靠版
- 後三角很小，**不要追重量**；動作品質遠比公斤數重要
