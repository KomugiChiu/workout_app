## 🔀 先建立正確形狀：擺盪 ≠ 深蹲

| | 擺盪 Swing（本篇） | 深蹲 Squat |
|---|---|---|
| 膝蓋 | 軟彎、**角度幾乎不變** | 大彎大伸 |
| 動力源 | **髖**前後（鉸鏈） | 膝＋髖上下 |
| 軌跡 | 壺鈴前後擺（鐘擺） | 身體上下 |
| 頂端 | 站直＋臀夾緊（站姿平板） | 站直 |
| 呼吸 | 鼻吸＋頂端短促吐氣 | 下吸上吐 |

> 檢驗法：後面放一張椅子，屁股往後碰椅＝對；膝蓋往前找腳尖＝錯。

## 🧘 準備姿勢（Hike Pass 啟動）

1. 壺鈴放身前約一腳距離；腳比肩寬，腳尖微外
2. 髖往後推、背平，一手（雙手版：雙手）把鈴**往胯下「 hiking 」拉回來**——像美式足球開球，這是第一下
3. 肩膀下沉遠離耳朵，手臂打直放鬆——從第一下起手臂就不出力

## 🏃 動作流程（4 拍循環）

1. **後擺**：鈴往胯下走，前臂貼近大腿內側；吸氣（鼻子短促一吸），腿後繃緊感拉滿
2. **爆發**：臀＋腿後同時收，髖往前「撞」——鈴被**甩**向前，不是被舉起
3. **頂端**：身體成站姿平板（臀夾緊、肋骨下收、頸延伸），鈴到約胸口高度即停；**短促吐氣「嘶」一聲**
4. **回放**：等鈴**掉回來**再屈髖接住，不要急著蹲下去追鈴；回到後擺銜接下一拍

## ✅ 檢查點

- 側面看：身體只在「鉸鏈前傾 ↔ 站姿平板」兩個形狀間切換
- 頂端鈴是**飄**到定位（失重感），不是手舉上去的——手舉＝肩膀代償
- 落地／接鈴**無聲**：腳掌全程黏地，腳跟不浮
- 脖子是背線的延伸，不抬頭看鈴

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 蹲著做（膝大彎） | 變深蹲甩鈴，腿後沒練到 | 膝蓋凍結，屁股往後找牆 |
| 用肩把鈴「舉」高 | 肩夾擠、前三角代償 | 鈴只到胸口；想「髖撞鈴飛」 |
| 頂端過度後仰 | 腰椎擠壓 | 頂端＝站直＋臀夾緊，不是往後躺 |
| 圓背 | 下背剪力 | 降重；胸口挺、肩離耳再啟動 |
| 太早屈膝追鈴 | 膝蓋擋住鈴路、下背代償 | 等鈴回到大腿附近再屈髖 |
| 憋氣硬撐 | 血壓飆、頭暈 | 每一下都「吸＋嘶」，呼吸跟上節奏 |

## 🔀 退階與進階

| 版本 | 用途 |
|------|------|
| 雙手壺鈴 RDL（慢速） | 還不會鉸鏈時先練這個，學會「屁股找牆」再上擺盪 |
| 雙手擺盪（本篇預設） | 輕裝日 3×15；8kg 起步剛好 |
| EMOM 擺盪 | 每分鐘開頭做 12 下，共 8–10 分鐘——省時心肺炸彈 |
| 單手擺盪 | 8kg 變輕後的升級；多抗旋核心，不換手連做一邊再換 |
| 換手擺盪（頂端換手） | 進階協調＋握力；先單手練穩再玩換手 |

## 📈 訓練量

- **輕裝日：3 × 15**，組間 60–90 秒；或 EMOM 12 下 × 8–10 分鐘二選一
- RPE 7–8：最後幾下髖速掉但背不圓；圓背＝重量超標或累了，先停
- 進步：同重量先加到 20 下／組 → 再延 EMOM 分鐘數 → 最後才換重鈴

## ⚠️ 安全提醒

- **下背當下刺痛** → 停：九成是蹲著做或圓背，回去看 Runna 慢動作重練鉸鏈
- 肩有夾擠病史：鈴只到肚臍高度就好（低擺盪），不追胸口高度
- 握力先爆（鈴要飛出去感）→ 放下休息，別用手腕硬勾；粉筆／止滑粉是合法外掛
- 場地：前後淨空，鈴飛出去不會砸到人或鏡子
