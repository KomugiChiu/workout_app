# 划船完整拆解（啞鈴＋彈力帶）

> **收錄日期**：2026-10-27（彈力帶章節增補）
> **定位**：A／B／C 三天循環的「補拉」主藥——修補「推多拉少」失衡（背闊＋菱形肌＋中下斜方）。
> **一句話**：手是鉤子，肘是引擎——把重量沿身體側面拉到髖旁，軀幹像釘在地板上。

## 🧘 準備姿勢（三點支撐）

1. 重訓椅前放啞鈴
2. **同邊手＋同邊膝**跪撐在椅上（右手拿鈴 → 右膝＋左手撐椅）
3. 從尾椎到後腦勺**一條直線**，背平如桌面
4. 工作臂自然垂直，肩膀沉住不聳
5. 雙腳踩地略開（比肩寬＝穩定基座）

## 🏃 動作流程（5 步）

1. **預備**：肩胛先下沉後收——不是從聳肩開始
2. **拉起**：想「**手肘往髖部口袋方向**」拉，肘貼身走 → 啞鈴到髖旁／下肋位置
3. **頂端**：肩胛擠向脊柱（「把肩胛放進後口袋」）停 1 秒
4. **下放**：2–3 秒控制，到底時肩胛允許前伸**一點點**，但軀幹**不轉**
5. **重複**：吐氣拉、吸氣放，單邊做完再換邊

## ✅ 檢查點

- 側面拍影片：**軀幹全程平行地板、不隨拉動旋轉**（畫面裡只有手肘在做功）
- 重量軌跡**直上直下向髖**，不是往胸口斜勾
- 拉到頂：感受點在**腋下外側 → 背闊**，不是前手臂
- 肘路線：想練**背闊**＝肘貼身收；若肘外開 90°＝變後三角（另一種用法，但補拉目標是背）

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 轉腰借力「甩」上去 | 下背扭轉壓力 | 降重量；想像軀幹被釘住 |
| 手腕先動、二頭主導 | 背刺激歸零 | 肘當引擎、手當鉤子 |
| 聳肩、肩胛沒收 | 斜方上束代償、頸痠 | 預備位先「肩離耳」再拉 |
| 肘外開成 90° | 變後三角飛鳥 | 肘貼身走「口袋路線」 |
| 下放砸太快 | 離心刺激全流失 | 2–3 秒控制 |
| 抬頭看鏡子 | 頸椎代償 | 後腦勺延續背線、看地面 |

## 💪 前臂痠痛期的握法調整

- **「手是鉤子」原則**：手指輕扣把手、啞鈴掛在虎口——是練背，不是練握力
- 前臂外側還痠（伸肌 DOMS）時：組間做手腕繞環
- 握力率先衰竭 → **直接上助力帶**：背訓練品質優先，不丟臉
- 彈力帶是痠痛期的好朋友：帶面寬、不用死扣，握力需求比啞鈴更低

## 📈 訓練量與漸進

- **3–4 組 × 10 下／邊**，組間 60–90 秒
- 重量：最後 2 下有餘力（RPE 7）
- 每週同日 **+1 下** 或 **+ 小幅重量**

## 🔀 變化與替代

| 版本 | 用途 |
|------|------|
| 無椅：四足跪姿單手划船（一膝一掌跪地） | 沒有可用椅面時 |
| 支撐手改撐架子／大腿（俯身更淺） | 穩定性要求更低、負荷更輕 |
| 胸前支撐划船（斜板躺著拉） | 最防作弊的版本，技術日選用 |
| 雙手彎身划船 | 想要更高總負荷、不需單邊矯正時 |

## 🎯 彈力帶划船（單手／雙手）

> 彈力帶和啞鈴最大差別：**越拉越重**（末端張力最大）。利用它：拉到底停 1 秒、**回放 3 秒**慢慢對抗——輕阻力也能把背練透。而且帶子握把粗、無需「扣緊」，對前臂痠痛期特別友善。

### 先選版本（四種，按情境對號入座）

| 版本 | 需要什麼 | 適合誰 |
|------|----------|--------|
| **A. 站姿踩帶俯身划船（雙手）** ⭐ 最推薦 | 一條長帶，無需固定點 | 居家沒門扣時；直接取代啞鈴彎身划船 |
| **B. 坐姿划船（雙手）** | 長帶繞腳底，或固定點 | 下背容易累的人；最穩、最適合新手 |
| **C. 固定點單手划船** | 帶子＋門扣／柱子 | 單邊矯正、握力最省（手可套腕帶環） |
| **D. 站姿面對固定點雙手划船** | 帶子＋胸高固定點 | 模擬纜繩划船；想站著練、順便練核心抗前引 |

### 通用設定：張力三旋鈕（阻力不夠／太大時調這個，不用先買新帶）

1. **站距／退後距離**：腳踩更開、離固定點更遠＝更重
2. **纏繞圈數**：帶子在腳下多繞半圈、手上多纏一圈＝更重
3. **雙股並用**：細帶對折當粗帶用；兩條可疊加

### A. 站姿踩帶俯身划船（雙手）

1. 雙腳踩住帶子中段（與肩同寬），雙手各抓一端
2. 髖往後推、俯身到軀幹約與地面平行，背平、手臂自然下垂——和啞鈴版同一個姿勢
3. 肘貼身往髖部拉，帶子末端貼著大腿外側上來
4. 頂端停 1 秒 → 3 秒慢放（對抗帶子把你往前扯的力量）

### B. 坐姿划船（雙手）

1. 坐地雙腿伸直，帶子中段繞過腳底（腳掌踩住防滑），雙手各抓一端；或帶子固定在身前柱子
2. 坐挺、膝微彎不鎖死，肩膀下沉遠離耳朵
3. 肘貼身往髖部拉 → 肩胛往脊柱擠 → 停 1 秒 → 3 秒慢放
4. 全程**不後仰借力**：軀幹可微幅後傾 5°，但不是躺下去划

### C. 固定點單手划船

1. 帶子固定在約腰高，面對固定點，單手抓一端、後退到有預拉張力
2. 前後腳站（弓步姿勢最穩），軀幹微前傾
3. 單手肘貼身往髖拉，另一手可扶大腿或自然擺動平衡
4. 做完一邊換邊；左右**先做弱邊**，次數向弱邊看齊

### D. 站姿面對固定點雙手划船

1. 帶子固定在胸高，雙手正握／對握，後退到手臂伸直時已有張力
2. 膝微彎、核心繃緊（身體會被往前拉——這就是額外的抗前引核心訓練）
3. 雙肘同時往髖部拉 → 停 1 秒 → 3 秒慢放，全程身體不晃

### 彈力帶專屬檢查點 ✅

- **預拉張力**：起始手臂伸直時帶子已經是繃的——鬆垮的前半段等於沒練
- **末端最重**：越接近身體越重，所以頂端 1 秒停留比啞鈴版更重要
- **回放是訓練**：3 秒慢放，不要被帶子「彈回去」
- **安全**：開練前先用力拽兩下測試固定點；帶子有裂紋、變黏就淘汰；放開帶子前先確認它不會彈到臉

### 彈力帶訓練量 📈

- **3–4 組 × 12–15 下**（帶子阻力曲線平滑，次數可比啞鈴多 2–5 下），組間 45–60 秒
- RPE 7–8：最後 2 下「拉到底有明顯掙扎但姿勢不跑掉」
- 漸進：同條帶先加次數（12 → 15 → 18）→ 再調三旋鈕加重 → 換粗帶
