# 農夫行走完整拆解（Farmer's Carry）

> **收錄日期**：2026-11-02
> **定位**：雙手持重行走——握力、上背、核心抗側屈、臀中肌一次打包，最實用的「功能性」動作。
> **一句話**：像提兩袋很重的菜走直線，身體不歪、肩不聳。

## 🔀 與「行李箱搬運」的差別

| | 農夫行走（本篇） | 行李箱搬運 Suitcase Carry |
|---|---|---|
| 負重 | **雙邊**等重 | **單邊** |
| 核心 | 抗伸展／穩定 | **抗側屈**（更強） |
| 握力 | 兩手平均 | 單手極限 |
| 適合 | 收尾、握力總量 | 矯正、單邊穩定 |

## 🧘 準備

1. 重量放身體兩側（啞鈴／壺鈴），**髖鉸鏈**下去拿（背平、不彎腰）
2. 握法：手指扣好、手腕中立，重量掛在虎口
3. 站起：臀夾、肋骨下收、肩膀下沉遠離耳朵
4. 重量選擇：**能走完 30–40 公尺而身體不歪**（歪了就太重）

## 🏃 流程（5 步）

1. 站直，視線前方
2. 小步、正常步幅往前走（不要跨大步）
3. 全程**身體像一塊板子**：不左右晃、不後仰
4. 呼吸順暢（2 步吸、2 步吐）
5. 到點後用髖鉸鏈放回重量，不要彎腰甩放

## ✅ 檢查點

- 肩膀水平、不聳肩
- 肋骨下收、不挺腰後仰
- 步幅自然、腳掌輕放（**無聲**）
- 走完**握力先爆**是正常的；**下背先痠**代表姿勢跑了

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 身體側傾／左右搖擺 | 核心代償、腰椎壓力 | 降重；想像頭頂有線往上拉 |
| 聳肩 | 斜方上束過勞、頸痠 | 肩胛下沉，手肘微彎 |
| 步幅太大 | 骨盆晃動、失去穩定 | 小步快走 |
| 重量太重硬撐 | 握力先爆、姿勢全崩 | 減重，先求走直 |
| 憋氣 | 血壓飆、頭暈 | 配合步伐呼吸 |
| 彎腰放下 | 下背風險 | 髖鉸鏈放回 |

## 🔀 變化

| 版本 | 做法 | 重點 |
|------|------|------|
| 行李箱搬運 | 單邊提 | 抗側屈最強 |
| 架上行走（Rack Carry） | 壺鈴架在肩前 | 核心前側＋上背 |
| 過頭行走（Overhead Carry） | 單手舉高 | 肩穩定、難度高 |
| 單手農夫行走 | 一手負重、一手空 | 介於兩者之間 |

## 📈 訓練量

- **3–4 趟 × 30–40 公尺**（或 40–60 秒），趟間休 45–60 秒
- 進步：先加距離（30→40m）→ 再加重量
- 放在課表**收尾**最合適（握力是共用資源，太早做會拖累後面）

## 🏋️ 你的器材

- 啞鈴 8–10kg ×2 → 雙邊農夫行走（總負重 16–20kg）
- 8kg 壺鈴 ×1 → 行李箱搬運（單邊）
- 1kg 啞鈴 → 技術練習／熱身

## ⚠️ 安全提醒

- 握力撐不住就放下，**不要用手指硬勾**
- 有高血壓者別憋氣、別做過頭行走
- 行走路線要淨空（轉身時最容易撞到東西）
