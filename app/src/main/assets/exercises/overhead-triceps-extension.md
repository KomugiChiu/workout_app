# 啞鈴過頭三頭伸展完整拆解（Overhead Triceps Extension）

> **收錄日期**：2026-11-02
> **定位**：手臂舉高、肘彎下放的伸展——**長頭優先**，手臂後側體積與線條的主力。
> **一句話**：手肘朝上、重量往頭後放，只有前臂在動。

## 🧠 為什麼是「長頭優先」

肱三頭**長頭**的起點在肩胛骨，會跨過肩關節：

- 手臂舉高（肩屈曲 160–180°）→ 長頭被拉長 → **刺激最大**
- 仰臥三頭伸展（肩約 90°）→ 長頭拉伸中等，偏外側／內側頭

> 這也是它與「仰臥三頭伸展」最大的差別——**不是停頓時間，是肩膀角度**。

## 💪 主練肌群

| 肌肉 | 角色 |
|------|------|
| 肱三頭（長頭） | **主力**，手臂後側體積 |
| 肱三頭（外側頭） | 輔助 |
| 肱三頭（內側頭） | 輔助 |
| 核心 | 站姿時穩定軀幹 |

---

## 🧘 準備

1. 站姿或**坐姿靠背**（肩膀活動度較差選坐姿）
2. 雙手捧住**一顆啞鈴上端**（杯握），或雙手各持一顆
3. 手臂舉過頭、手肘朝前上方，肋骨下收、核心繃緊
4. 重量 3–5kg 起（能完整下放且不拱腰）

## 🏃 做法（5 步）

1. 手臂伸直在頭頂，手肘靠近耳朵
2. 吸氣，肘彎、重量慢慢下放到**頭後**
3. 下放到「長頭有拉伸但肘不痛」的位置即停
4. 吐氣，三頭發力伸回，頂端收緊 1 秒
5. 回程 3 秒慢放，全程**上臂不往前倒**

## ✅ 檢查點

- 手肘**朝上、靠近耳朵**，不往外開
- 只有前臂在動，上臂幾乎不動
- 腰不拱、肋骨不翻（站姿最容易犯）
- 下放深度以「不痛」為界，不硬碰頭

## 🔴 常見錯誤

| 錯誤 | 後果 | 修正 |
|------|------|------|
| 手肘外開 | 長頭張力跑掉 | 手肘夾向耳朵 |
| 上臂往前倒 | 變成半個肩推 | 上臂固定垂直 |
| 拱腰後仰 | 下背壓力 | 收肋骨、核心繃緊；改坐姿 |
| 重量太重 | 行程變短、借力 | 3–5kg 起，完整行程優先 |
| 下放太深硬壓 | 肘關節壓力 | 拉到緊就好，不追角度 |
| 頭往前伸 | 頸椎代償 | 下巴微收、頸延伸 |

## 🔀 變化

| 版本 | 做法 | 重點 |
|------|------|------|
| 坐姿靠背 | 椅背 60–75°，雙手持鈴 | 肩膀壓力最小、最推薦入門 |
| 單手版 | 單手啞鈴，另一手輔助 | 矯正左右差 |
| 壺鈴版 | 8kg 壺鈴雙手捧鈴 | 重心在把手下方，手腕中立 |
| 彈力帶版 | 踩帶或固定點，雙手持帶過頭 | 頂端阻力最大 |
| EZ 槓版 | 槓鈴較好對稱 | 兩手平均发力 |

## 📈 訓練量

- **3 組 × 10–12 下**，組間 60 秒
- RPE 7–8：最後 2 下有餘力、動作不變形
- 放在推日或手臂日**最後**（大動作之後）
- 與三停三頭同天時，各降為 **2 組**（避免肘過載）

## 🏋️ 你的器材

- 啞鈴 3–5kg ×2 或單顆雙手捧
- 8kg 壺鈴：雙手捧鈴版（注意手腕中立）
- 30kg 彈力帶：踩帶過頭版；帶子偏重時改單手

## ⚠️ 安全提醒

- 肩膀舉高會痛／活動度不足 → 改**坐姿靠背 60–75°**
- 手肘後側刺痛（非肌肉燒灼）→ 停，降重量、縮行程
- 不要為了「放到更低」而拱腰或硬壓頭後
- 曾經肩夾擠、肘傷 → 先諮詢醫師／物理治療師
